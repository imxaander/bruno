# Special Systems

Detailed tables for the sub-systems owned by Origin Vaults and the hidden artifacts.
See `origins.md` for the origin cards themselves.

## 1. Pandora's Box (Grand Architect)

Constructed by the Grand Architect origin. The box can only be used once you use a vault.
Upgrade the box by using better vaults. Every round, there is a chance to gain a random
vault; the better the box's upgrade, the higher the chance.

| Vault gained  | Silver Upgrade | Gold Upgrade | Diamond Upgrade | Source |
| ------------- | -------------- | ------------ | --------------- | ------ |
| Silver Vault  | 10%            | 20%          | 30%             | p.9    |
| Gold Vault    | 5%             | 10%          | 15%             | p.9    |
| Diamond Vault | 1%             | 3%           | 5%              | p.9    |

## 4. Artifacts: Boot and Leg

Hidden cards that power the Tier I card **Bootleg** ("Find Boot and Leg").

| Id              | Name | Text (verbatim)                                              | Source |
| --------------- | ---- | ------------------------------------------------------------ | ------ |
| `artifact-boot` | Boot | Powerful magic withers from it…                              | p.3    |
| `artifact-leg`  | Leg  | _(mirror/upside-down flavor text on p.4, inverse of Boot's)_ | p.4    |

The leg flavor text is rendered upside-down in the PDF and did not extract as readable text;
it is a visual parallel of Boot's line. Bootleg lets you "Pick a power from the artifact that
you crafted" — implying crafted artifact powers are gained by finding these two cards.
